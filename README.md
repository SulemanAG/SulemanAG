## 🌟 Featured Projects

### [🏦 LedgerCore](https://github.com/SulemanAG/LedgerCore) — High-Throughput Financial Transaction Infrastructure
> *"Processing 1K+ transactions/sec with absolute consistency"*

<details>
<summary><b>🔍 Click to expand</b></summary>

- **Tech Stack:** Spring Boot, PostgreSQL, Apache Kafka, Redis
- **Scale:** Supports 1K+ TPS across 10K+ simulated accounts
- **Key Features:**
  - Double-entry ledger system with wallet management
  - Idempotent transactions & concurrency controls
  - Transactional outbox pattern for reliable event delivery
  - Event-driven balance projections & audit logs
  - Dead-letter queues & retry handling for failure scenarios
- **Testing:** Unit, integration, and concurrent workload testing with JMeter
</details>

  - Database indexing & Redis caching for 35% latency reduction
  - Asynchronous processing for improved performance

</details>
